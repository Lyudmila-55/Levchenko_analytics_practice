# Руководство пользователя мобильного приложения «НаПоправку»

## Введение
«НаПоправку» — это мобильное приложение, разработанное для того, чтобы помочь вам восстановится после травм, контролировать хронические состояния и наблюдать общее состояние организма. 
Документ описывает ключевые функции, интерфейс, настройки и процедуры взаимодействия с приложением.

## Целевая аудитория
Приложение «На поправку» разработано для пользователей, которые:

- Проходят курс восстановления после травм или заболеваний.
- Имеют хронические заболевания и нуждаются в системном контроле состояния.
- Перенесли оперативные вмешательства и находятся в реабилитационном периоде.
- Следят за своим здоровьем и хотят систематизировать медицинские данные.

## Установка приложения
### Android:
1. Откройте Google Play.
2. В строке поиска введите  "На поправку".
3. Нажмите "Установить".
4. Дождитесь завершения установки и нажмите "Открыть".

### iOS:
1. Откройте App Store.
2. В строке поиска введите  "На поправку".
3. Нажмите "Скачать".
4. Подтвердите установку с помощью Face ID/Touch ID или пароля Apple ID.
5. Дождитесь завершения установки и нажмите "Открыть".

## Создание учетной записи
После установки приложения вы можете создать учетную запись несколькими способами:

1. Откройте приложение «НаПоправку».
2. Нажмите «Зарегистрироваться» или «Создать учетную запись».
3. Выберите один из вариантов регистрации:

- **Через электронную почту:**
    - Введите адрес электронной почты.
    - Создайте надежный пароль (не менее 8 символов).
    - Заполните дополнительные данные (если требуется).
    - Примите условия использования и политику конфиденциальности.
    - Нажмите «Создать учетную запись».
    - Подтвердите email через ссылку в письме.

- **Через социальные сети:**
    - Выберите иконку нужного сервиса (ВКонтакте, Apple ID).
    - Разрешите доступ к базовой информации.
    - При необходимости заполните недостающие данные.
    - Примите условия использования.

После успешной регистрации вы получите доступ к полному функционалу приложения.

## Раздел "Записи"
### Запись на процедуру:
1. Перейдите в раздел "Запись".
2. Нажмите кнопку "Найти врача или клинику" (иконка лупы).
3. Выберите нужную процедуру:
   - Из списка популярных услуг,
   - Через поиск (введите название вручную)
4. Просмотрите список доступных клиник с основной информацией (стоимость, адрес клиники, рейтинг, отзывы пациентов, контактные данные и тд).
5. Нажмите "Записаться" у выбранной клиники.
6. Заполните обязательные данные:
   - ФИО (полностью),
   - Номер телефона (для обратной связи).
7. Нажмите «Записаться».

### Отслеживание заявок на приём
В разделе "Запись" вы можете перейти в подраздел "Заявки", где доступно:
- Просматривать статус заявок, 
- Просматривать информацию о записи (название клиники, адрес клиники, контактный номер, процедуру, стоимость процедуры, дата создания заявки и т.д.),
- Позвонить в клинику,
- Просматривать историю обращений,
- Повторно записываться на прием.

## Управление профилем и медицинской картой
### Управление профилем
1. Перейдите в раздел «Профиль».
2. Здесь вы можете обновить свои личные данные (имя пользователя, номер телефона, город, почта).
3. Данные автоматически сохраняются после внесения изменений.

### Настройка медицинской картой
1. Перейдите в раздел «Профиль».
2. Выберите «Медкарты».
3. Выберите пациента, для которого нужно добавить или изменить данные.
4. Нажмите кнопку «Заполнить» рядом с выбранным профилем.
5. На первом этапе укажите:
   - Основные данные:
     - ФИО пациента,
     - Номер телефона,
     - Дату рождения,
     - Пол,
     - Тип пациента (я/родственник).
   - По желанию можно добавить фотографию пациента.
6. Нажмите «Следующий шаг».
7. На втором этапе заполните медицинскую информацию:
   - Антропометрические данные (рост, вес),
   - Сведения о:
     - Перенесённых травмах,
     - Операциях,
     - Принимаемых лекарствах,
     - Аллергических реакциях,
     - Особенностях образа жизни,
8. Для сохранения данных нажмите кнопку «Сохранить».

## Добавление документов
1. Перейдите в раздел «Профиль».
2. Выберите «Мои документы».
3. Нажмите на иконку «+» в нижнем правом углу экрана.
4. Выберите способ добавления:
   - **Выбрать фото из галереи**
     - Откроется доступ к медиатеке вашего устройства,
     - Можно выбрать несколько файлов сразу,
     - Поддерживаются форматы: JPG, PNG, PDF.
   - **Сделать фото**
     - Разрешите доступ к камере,
     - Сфотографируйте документ,
     - Подтвердите или переснимите.
   - **Отправить почтой**
     - Прикрепите файлы из почтового клиента,
     - Документы автоматически сохранятся в приложении.
   - **Новая папка**
     - Создайте тематическую папку (например, «Анализы 2024»),
     - Перемещайте документы между папками.
5. Добавьте название документа.
6. Нажмите «Создать».

## Конфиденциальность данных
«НаПоправку» серьёзно относится к вашей конфиденциальности. Все ваши медицинские данные хранятся в зашифрованном виде и не передаются третьим лицам без вашего явного согласия. Более подробную юридическую информацию вы можете найти в разделе: «Профиль» → «Настройки» → «Юридическая информация».
